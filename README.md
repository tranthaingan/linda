# linda

一个专为酒馆打造的轻量级预设缝合工具

✨ 核心亮点（看图或亲自体验）：

1️⃣ 可视化主/次体选择：最多可以选 1 个主体预设和 6 个次体预设，一键进入缝合界面。

2️⃣ 丝滑 UI 交互：完全模仿手记的便利交互。每个词条是一个独立的卡片，带下拉箭头（V），点开就能直接修改提示词内容。

3️⃣ 智能搜索置顶：词条太多找不到？不管是选预设还是选词条，输入框直接输入关键词，名字匹配的会自动排在最前面，不用点搜索按钮，实时响应。

4️⃣ 无限撤销 + 防误触：写错、删错、拖拽乱了？支持深度撤销（Undo）！删除词条需要二次确认，防止手滑。

5️⃣ 安全保存：绝不覆盖你原来的预设！点击“另存为”会生成一个全新的预设，并自动保存进酒馆列表中，刷新即可使用。

6️⃣ 自动适配主题：颜色会自动跟随你当前酒馆的主题，甚至带夜间模式保护。


🌟 更多贴心细节 & 进阶玩法：

7 兼容原生结构（不破坏文件夹）：
酒馆里有些预设是用纯文本伪装的“文件夹”，有些是原生嵌套结构。本工具在缝合时做了扁平化安全处理，无论次体预设有多深，都能准确提取词条；缝合进主体预设时，也不会破坏你原有的 JSON 层级和格式。

8 真正为手机端打造：
平时在手机上玩酒馆，想改个预设简直痛不欲生。这个工具采用了卡片式堆叠，长按拖拽排序，无论是搜索、展开还是修改，单手就能丝滑操作，彻底告别瞎眼翻找。

9 兜底悬浮按钮：
酒馆的UI版本繁多，如果你的预设界面没刷出那个「🧵 预设缝合神器」的入口长条，别慌！屏幕左下角会自动生成一个悬浮按钮，点一下照样能进入。

💡 常见问题 (FAQ)：

· Q：缝合后，我原来的预设会被覆盖或弄坏吗？
  · A：绝对不会！ 这个工具的核心逻辑就是“只读原文件，另存新文件”。你缝完点击“另存为”，它会生成一个带“-缝合”后缀的新预设，你原来的预设连一个标点符号都不会变。
· Q：缝合进去的次体词条，位置在哪里？
  · A： 你点击次体的哪个词条，它就会精准地缝在你选中的那个主体词条的正下方。如果想调整位置，直接按住左边的“六点抓取图标”上下拖拽即可。
· Q：为什么有些词条名字前面有个 ✱ 符号，而且不能编辑？
  · A： 那是酒馆系统的底层占位条目（比如 chatHistory 这种），为了保证不出错，工具自动将其锁定只读，这是正常的安全保护机制哦。

⚠️ 使用说明：

· 安装方式：复制附件中的 JSON 文件内容，在「酒馆助手」→「脚本库」→「新建脚本」中粘贴并开启。
· 启用后，刷新酒馆，在预设页面（提示词上方）会多出一个「🧵 预设缝合神器」的长条入口，点击即可使用。（如果在某些特殊布局下没找到长条，屏幕左下角会自动生成一个悬浮按钮作为兜底）。
